# TIS-99

A [TIS-100](https://www.zachtronics.com/tis-100/) simulator degenerated by 1 due to the lack of a fancy (20th century-ish) debugging interface. 

You probably won't need this because [TIS-100-CXX](https://github.com/killerbee13/TIS-100-CXX) already exists, with more features than this. This project is made merely for fun.

### Compile
Example using gcc with optimizer flags:
``gcc main.c puzzle.c parser.c sim.c -s -O2 -o TIS-99``
To make it print the current board state every cycle (you need to press key to step every cycle): 
``gcc main.c puzzle.c parser.c sim.c -s -O2 -DTIS_DEBUG -o TIS-99-dbg``
You may try with any compiler and any flags you like.

### Usage (currently)
``TIS-99 [file path]``

Puzzle will be **deducted from the file name**.
